# Orbit

Аналитика подписчиков Instagram по официальному архиву «Скачать информацию»: кто подписался, кто отписался, взаимные, «не в ответ», фанаты, графики роста. Без пароля Instagram — архив разбирается в браузере, данные хранятся только на устройстве.

Деплой: статический `index.html` — Vercel подхватывает без настроек.
